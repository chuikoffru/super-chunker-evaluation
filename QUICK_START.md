# 🚀 Быстрый запуск SuperChunker

## Простая установка и запуск

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Запустите приложение
```bash
python run.py
```
**или**
```bash
streamlit run app.py
```

### 3. Откройте браузер
Перейдите по адресу: http://localhost:8501

## 🎯 Быстрый тест

1. **Выберите методы**: В боковой панели выберите 2-3 метода для сравнения
2. **Оставьте образец текста**: Используйте предустановленный текст про ИИ
3. **Нажмите "Запустить чанкование"**: Дождитесь обработки
4. **Изучите результаты**: Перейдите по вкладкам для анализа

## 📊 Что смотреть в результатах

- **Сводка**: Сравнение основных метрик
- **Графики**: Визуальное сравнение методов  
- **Детали чанков**: Просмотр содержимого отдельных фрагментов
- **Конфигурации**: Используемые параметры

## 🛠 Настройка параметров

Каждый метод имеет свои параметры в боковой панели:
- **Размер чанков** - основной параметр размера
- **Перекрытие** - количество повторяющегося контента
- **Разделители** - символы для разбиения текста

## 💡 Рекомендации по использованию

### Для коротких текстов (< 5000 символов)
- Используйте "Предложения" или "Абзацы"
- Настройте небольшие размеры чанков

### Для длинных документов (> 10000 символов)  
- Попробуйте "Рекурсивный" или "Семантический"
- Увеличьте размеры чанков до 1000-2000 символов

### Для технических текстов
- "Токены" хорошо работают с кодом
- "Рекурсивный" сохраняет структуру

## ⚠️ Известные ограничения

- Семантический метод требует время на загрузку модели при первом запуске
- Большие тексты (>50KB) могут обрабатываться медленно
- Семантический анализ потребляет больше памяти
