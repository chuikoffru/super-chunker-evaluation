# ✂️ SuperChunker

**Инструмент для тестирования различных методов чанкования текстов**

SuperChunker — это приложение на базе Streamlit, которое позволяет сравнивать и анализировать различные методы разбиения длинных текстов на фрагменты (чанки). Приложение предоставляет удобный интерфейс для экспериментов с параметрами и визуального анализа результатов.

## 🎯 Возможности

### Методы чанкования
- **По символам** - разбиение по количеству символов с настраиваемыми разделителями
- **Рекурсивный** - умное разбиение с приоритетом разделителей
- **По токенам** - разбиение на основе токенизации GPT/OpenAI моделей
- **По предложениям** - разбиение по границам предложений с NLTK
- **По абзацам** - разбиение по границам абзацев
- **Семантический** - разбиение на основе семантической схожести предложений
- **Фиксированный размер** - простое разбиение блоками фиксированного размера

### Настраиваемые параметры
- Размер чанков (символы/токены/предложения/абзацы)
- Величина перекрытия между чанками
- Разделители для текста
- Пороги семантической схожести
- Модели токенизации (GPT-3.5, GPT-4, и др.)

### Анализ и визуализация
- **Сводные таблицы** с метриками для каждого метода
- **Интерактивные графики** сравнения методов
- **Распределение размеров** чанков с гистограммами
- **Детальный просмотр** содержимого чанков
- **Статистика исходного текста**
- **Рекомендации** по выбору оптимального метода

## 🎛 Параметры методов

### Символы / Рекурсивный
- `chunk_size`: размер чанка в символах (100-5000)
- `chunk_overlap`: перекрытие в символах (0-500)
- `separator`: разделитель текста (по умолчанию `\n\n`)

### Токены
- `chunk_size`: размер чанка в токенах (50-2048)
- `chunk_overlap`: перекрытие в токенах (0-200)
- `model_name`: модель токенизации (gpt-3.5-turbo, gpt-4, и др.)

### Предложения
- `sentences_per_chunk`: количество предложений в чанке (1-20)
- `overlap_sentences`: перекрытие в предложениях (0-5)

### Абзацы
- `paragraphs_per_chunk`: количество абзацев в чанке (1-10)
- `overlap_paragraphs`: перекрытие в абзацах (0-3)

### Семантический
- `similarity_threshold`: порог схожести для разделения (0.1-0.9)
- `max_chunk_size`: максимальный размер чанка в символах (500-3000)

### Фиксированный размер
- `chunk_size`: размер чанка в символах (100-5000)
- `overlap`: перекрытие в символах (0-500)

## 🔬 Метрики анализа

- **Количество чанков** - общее число полученных фрагментов
- **Средний размер** - среднее количество символов в чанке
- **Мин/Макс размер** - границы размеров чанков
- **Стандартное отклонение** - показатель стабильности размеров
- **Время обработки** - скорость выполнения метода

## 🤝 Расширение функционала

### Добавление нового метода чанкования

1. Создайте класс, наследующий от `BaseChunker`
2. Реализуйте методы `chunk_text()` и `get_params()`
3. Добавьте класс в словарь `CHUNKERS` в `chunkers.py`
4. Добавьте обработку параметров в функцию `render_chunker_params()` в `app.py`

## 📝 Примеры использования

### Сравнение методов для технических документов
1. Выберите методы: "Рекурсивный", "По абзацам", "Семантический"
2. Загрузите техническую документацию
3. Настройте размеры чанков: 800-1200 символов
4. Сравните стабильность размеров и качество разделения

### Оптимизация для RAG систем
1. Выберите методы: "Токены", "Семантический"
2. Установите размер токенов: 256-512
3. Настройте перекрытие: 10-20%
4. Анализируйте баланс между количеством чанков и их информативностью

### Препроцессинг для ML моделей
1. Используйте метод "Фиксированный размер"
2. Установите точный размер под требования модели
3. Минимизируйте перекрытие для экономии ресурсов

## 🐛 Известные ограничения

- Семантический чанкер требует загрузки модели sentence-transformers (~90MB)
- Токенный чанкер может быть медленным на очень больших текстах
- Обработка файлов ограничена текстовыми форматами
