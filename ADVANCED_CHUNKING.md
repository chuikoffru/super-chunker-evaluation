# 🧠 Advanced Semantic Chunking

Продвинутые методы семантического чанкования с PSR анализом для SuperChunker.

## 🌟 Обзор

Этот модуль предоставляет три продвинутых метода семантического чанкования:

### 1. 📈 Cumulative (Кумулятивный)
- **Принцип**: Накопление семантического контекста
- **Как работает**: Каждое новое предложение сравнивается с усредненным вектором всего текущего чанка
- **Преимущества**: Лучшая контекстуальная память, устойчивость к "шуму"
- **Лучше всего для**: Связные тексты, документы с последовательным изложением

### 2. 🏗️ Hierarchical (Иерархический)  
- **Принцип**: Многоуровневое чанкование
- **Как работает**: 
  1. Разбивка по абзацам
  2. Семантическое чанкование внутри абзацев
  3. Объединение близких чанков
- **Преимущества**: Учитывает структуру документа, сохраняет логические блоки
- **Лучше всего для**: Структурированные документы, статьи, книги

### 3. 🎯 Adaptive (Адаптивный)
- **Принцип**: Динамический порог на основе статистики
- **Как работает**: Анализирует распределение схожести и вычисляет оптимальный порог автоматически
- **Преимущества**: Самонастройка под характер текста, универсальность
- **Лучше всего для**: Разнородный контент, неизвестные типы текстов

## 📊 PSR Анализ

### Что такое PSR?

**PSR** - это система оценки качества чанкования по трем критериям:

#### 🚀 Performance (Производительность)
- **Скорость обработки** - символов в секунду
- **Использование памяти** - МБ во время работы  
- **Процент ошибок** - надежность выполнения

#### 📈 Scalability (Масштабируемость)
- **Фактор масштабируемости** - как производительность зависит от размера
- **Коэффициент эффективности** - чанков в секунду
- **Корреляция размер-время** - линейность роста времени

#### 🎯 Reliability (Надежность)
- **Консистентность размеров** - равномерность чанков
- **Семантическая когерентность** - связность содержания
- **Точность границ** - качество разделения предложений

### PSR Score

Итоговая оценка вычисляется как взвешенная сумма:
```
PSR Score = Performance×35% + Scalability×30% + Reliability×35%
```

**Оценки:**
- A+ (0.9-1.0) - Отлично
- A (0.8-0.9) - Очень хорошо  
- B+ (0.7-0.8) - Хорошо
- B (0.6-0.7) - Удовлетворительно
- C+ (0.5-0.6) - Ниже среднего
- C (0.4-0.5) - Плохо
- D (0.3-0.4) - Очень плохо
- F (0.0-0.3) - Неудовлетворительно

## 🚀 Быстрый старт

### 1. Запуск тестовой страницы

```bash
# Способ 1: Прямой запуск
python advanced_semantic_test.py

# Способ 2: Через вспомогательный скрипт
python run_advanced_test.py

# Способ 3: Streamlit напрямую
streamlit run advanced_semantic_test.py
```

### 2. Использование в коде

```python
from chunkers.semantic import AdvancedSemanticChunker
from analyzer_advanced import PSRAnalyzer

# Создание чанкера
chunker = AdvancedSemanticChunker(
    method='cumulative',  # или 'hierarchical', 'adaptive'
    similarity_threshold=0.7,
    max_chunk_size=1000,
    api_key='your-openai-key'  # необязательно, fallback на Spacy
)

# Чанкование текста
chunks = chunker.chunk_text("Ваш текст здесь...")

# PSR анализ
analyzer = PSRAnalyzer()
test_texts = ["текст1", "текст2", "текст3"]
results = analyzer.analyze_chunker(chunker, test_texts, "cumulative")

print(f"PSR Score: {results['psr_score']['total_psr_score']:.2f}")
print(f"Оценка: {results['psr_score']['grade']}")
```

## ⚙️ Конфигурация

### Основные параметры

| Параметр | Описание | По умолчанию | Диапазон |
|----------|----------|--------------|----------|
| `method` | Метод чанкования | 'cumulative' | cumulative, hierarchical, adaptive |
| `similarity_threshold` | Порог схожести | 0.7 | 0.1-1.0 |
| `max_chunk_size` | Макс. размер чанка | 1000 | 500-3000 |
| `api_key` | OpenAI API ключ | '' | - |
| `timeout` | Таймаут API | 30 | 10-120 |
| `max_retries` | Повторные попытки | 3 | 1-10 |

### API настройки

```python
# OpenAI (по умолчанию)
chunker = AdvancedSemanticChunker(
    api_url="https://api.openai.com/v1/embeddings",
    model_name="text-embedding-ada-002"
)

# Azure OpenAI
chunker = AdvancedSemanticChunker(
    api_url="https://your-resource.openai.azure.com/openai/deployments/your-deployment/embeddings",
    api_key="your-azure-key"
)

# LocalAI / Ollama
chunker = AdvancedSemanticChunker(
    api_url="http://localhost:8080/v1/embeddings",
    model_name="your-local-model"
)
```

## 📈 Интерпретация результатов

### Когда использовать каждый метод:

#### Cumulative ✅
- **Хорошо для**: Научные статьи, техническая документация, последовательные тексты
- **Признаки**: Высокая семантическая когерентность, средняя производительность
- **Избегать**: Разрозненные тексты, списки, каталоги

#### Hierarchical ✅  
- **Хорошо для**: Книги, отчеты, структурированные документы
- **Признаки**: Лучшая масштабируемость, сохранение структуры
- **Избегать**: Тексты без четкой структуры абзацев

#### Adaptive ✅
- **Хорошо для**: Смешанный контент, неизвестные тексты, универсальные задачи  
- **Признаки**: Высокая надежность, автонастройка
- **Избегать**: Когда нужен строгий контроль над размером чанков

### Анализ PSR метрик:

**High Performance (> 0.7):**
- Быстрая обработка
- Низкое потребление памяти
- Подходит для production

**High Scalability (> 0.7):**
- Линейный рост времени
- Обрабатывает большие тексты
- Стабильная производительность

**High Reliability (> 0.7):**
- Качественное разбиение
- Консистентные результаты  
- Сохранение семантики

## 🔧 Устранение неполадок

### Частые проблемы:

#### 1. Ошибка API ключа
```
ValueError: API ключ не найден и Spacy недоступен
```
**Решение:** Установите API ключ или установите Spacy:
```bash
export OPENAI_API_KEY='your-key'
# или
pip install spacy
python -m spacy download ru_core_news_md
```

#### 2. Медленная работа
```
Low Performance Score (< 0.5)
```
**Решение:** 
- Используйте локальные модели (Spacy)
- Уменьшите размер тестовых текстов
- Выберите более быстрый метод (Adaptive)

#### 3. Плохое качество чанкования
```
Low Reliability Score (< 0.5) 
```
**Решение:**
- Настройте similarity_threshold (0.6-0.8)
- Попробуйте другой метод
- Проверьте качество входного текста

#### 4. Проблемы с памятью
```
High Memory Usage (> 100MB)
```
**Решение:**
- Уменьшите max_chunk_size
- Обрабатывайте тексты частями
- Используйте метод Hierarchical
